BACKUP & RESTORE

Backups are encrypted with a password of your choice (separate from the master password). Store the file somewhere safe — anyone with the file AND the backup password can recover your wallets.

SETTINGS
PASSWORD RECOVERYoff

When enabled, your master password is stored in this device's OS keychain (Keychain on macOS, Credential Manager on Windows, libsecret on Linux). You can then reveal it after passing OS authentication — useful when you've forgotten the copy you wrote down, or when setting up a new device.

Tradeoff: anyone with access to your unlocked OS session can also extract the password from the keychain. Leave this off unless you need it.
